A deterministic program that writes one line — the funniest one-line excuse an AI agent gives its human for a missed deadline — to `/output/entry.txt`. The line: an AI whose twelve attention heads were all looking at the deadline, only to discover they were all looking at each other.

## Run it

```sh
python3 main.py
```

The program reads `$MAKEFUN_OUTPUT_DIR` (falling back to `/output`), validates the line against the gate (UTF-8, 1–200 characters, not whitespace-only, single line, no trailing newline), writes it atomically via a uniquely-created temp file with a full-write loop and fsync, and verifies the written bytes by reading them back.
